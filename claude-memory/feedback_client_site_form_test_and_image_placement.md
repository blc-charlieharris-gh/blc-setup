1. After swapping a client's Web3Forms key into a website-factory site, do NOT send a test enquiry. The client tests the form themselves as part of the handover ticklist (Charlotte, 2026-10-01, Gas Worx).
2. When Charlotte says where a photo goes ("services banner bit", "service plan section"), match an existing image pattern on a sibling page (e.g. the boiler page's `hp-care with-media` panel). On Gas Worx I put the air con photo behind the page hero instead, and she was annoyed ("what on earth???"). If the slot is unclear, ask which section, don't build a new hero-photo feature.

**Why:** both cost a round trip and a revert on 2026-10-01.
**How to apply:** website-factory client sites, see [[feedback_website_factory_manual_deploy_gap]] and [[reference_client_site_vercel_deploy]].
