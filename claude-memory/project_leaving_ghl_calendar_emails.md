When we move calendars off GHL (Charlotte 2026-10-18), every calendar booking must start our OWN booking emails (nicer, Email client look), replacing GHL's confirmation/reminder emails. Staff booking from a client's portal stays silent to the client (client-portal toNotify = !!mine since 10-18). Client self-bookings get the confirmation.

**Why:** GHL's own emails fire today (Madola got one when staff booked an access call on 10-18).
**How to apply:** put "our own booking emails for every calendar" on the leaving-GHL plan; see [[feedback-all-client-emails-from-email-builder]].
