Whether a new campaign goes in Meta's finance special category (pins only, no postcodes) is always the person's choice. The Hub may suggest one: like the ad set being copied, else from the brief or code. It must never enforce it.

**Why:** Charlotte 10-27, setting up AS06 from AS04 for Castle Eco. AS04 is named "Finance" but isn't in the category and targets postcodes. Set it up in Meta would have forced AS06 into the category with pins. Her words: "that should always be option as to whether we set it as a finance campaign or not, you can suggest, but not enforce."

**How to apply:** any set-up, copy or location tool that touches the finance category offers both options with a suggested default and a short reason. Warnings like "Meta may ask for the category later" are fine; blocks are not. Related: [[reference_meta_finance_special_category_rules]].
