---

For a logo's light-background and dark-background versions, keep the colour of any element that still reads on that background (e.g. Core Electrics' gradient "C" on white and on black), and only switch elements that would disappear (white lettering on white) to black or white. Staff also need to preview both versions.

**Why:** Charlotte (2026-09-18) saw the brand guidelines PDF showing the logo as flat black/white and said the coloured mark was contrast-approved on both and should have stayed in colour.

**How to apply:** Never present one-colour (mono) versions as "the" light/dark versions. Mono is for single-colour printing only (embroidery, engraving). Always show colour-kept versions to staff before building. See [[project-crew-logo-studio]].
