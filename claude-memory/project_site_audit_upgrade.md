**How to apply:** for a new client site, follow Gas Worx's hardening as the standard: self-hosted fonts, CSP + HSTS + framing/referrer/permissions headers in vercel.json, noindex only via `has: host (.*)\.vercel\.app`, canonical/sitemap on the end domain, embeds behind the cookie gate (data-consent-src), heading order, 24px tap targets.
