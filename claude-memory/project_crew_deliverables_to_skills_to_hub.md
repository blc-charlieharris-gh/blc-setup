Charlotte 2026-10-14: order of work for Crew client deliverables (social set-up/audit, Google profile, website build + site audit, logo, SiteScore, etc.):
1. Nail each deliverable first (started 10-14 with the Elect social audit, Arktek/Retrofit live-site update, website audit false passes).
2. Then create "real strong" Claude skills for each deliverable, so working on them is faster and consistent.
3. Then use those defined skills as the spec to build further Hub functionality, so staff do each one "at the touch of a button".

**Why:** the deliverables keep needing rework (gaps found late, e.g. the 10-13 website audit review); codified skills make the method repeatable before it's automated.
**How to apply:** while fixing a deliverable, note the steps, standards and gotchas that a skill would need (keep them in the repo, e.g. the deliverable's process doc). Don't jump to skills or Hub buttons for a deliverable until Charlotte agrees it's nailed. Related: [[project_social_setup_area]], [[project_client_area_plan]], [[feedback_rules_not_one_off_fixes]].
