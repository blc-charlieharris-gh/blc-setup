BLC sells InstallrHub website audits ("SiteScore") to installer prospects, then upsells a **£1,500 conversion-built website**. Charlotte builds a co-branded HTML report per prospect from the `meta-access` project.

**The report** (conversion-first weighting): InstallrHub-branded (green `#4a9e4f`, charcoal `#1a202c`/`#1e2d3d`, gold `#fbbf24`, real logo SVG from `site-installrhub/installrhub-static/images/`), with the client's brand threaded in (their logo in a "Prepared exclusively for" band + top-bar chip; their brand colour used to fill weak scores). Structure: dual score (kerb-appeal vs conversion-engine) + 8-area scorecard + "what's solid / carries over" + findings-with-screenshots + root-cause + "two ways forward" (£1.5k rebuild = recommended) + 4-stage build plan (must include DESIGN, not just repositioning, or it reads as "moving things around"). Tone: audit, not desperate sell; the sales guy does the selling. Score realistically low (Synergi 45, Gas Worx 42) so it doesn't read "fine, leave it". Capture screenshots with playwright-core headless-shell (dismiss cookie/popup modals for a clean hero; the modal itself is often a finding).

**Hosting**: gated static page at `installrhub.com/sitescore/<slug>` (canonical redirects to `www.installrhub.com/sitescore/<slug>`). Repo = `site-installrhub/installrhub-static` (Vercel project `installrhub-site`, team blc-promotions). Static multi-page site (cleanUrls, folder/index.html). Add `sitescore/<slug>/index.html` as a full standalone doc (wrap the report fragment with doctype/head/body). **Soft client-side password gate**, password = the slug (synergi, gasworx). Gate logo must use hardcoded `fill=` attributes, NOT the shared `.logo-*` classes (inline SVG `<style>` leaks across all logos on the page).

**Deploy**: NOT `website.installrhub.com` (that domain path-strip-redirects to installrhub.com). Do NOT self-deploy (`vercel --prod` is blocked by the Serafim sign-off boundary). Instead: branch `sitescore/<slug>` off `main`, commit the one file (NO `Co-Authored-By`, Vercel blocks it), push, open PR; **user/Serafim merges to main → Vercel auto-deploys**. See [[feedback_serafim_signoff_and_handoffs]], [[reference_git_auth]].

Done so far: Synergi SW (45/100, live), Gas Worx (42/100, merged live), Arktek Group (45/100, slug `arktek`, password `arktek`). Arktek v1 (46/100) merged live via PR #4; a review revision (v2, 45/100) is on branch `sitescore/arktek-revised` (PR https://github.com/blc-charlieharris-gh/site-installrhub/pull/new/sitescore/arktek-revised) awaiting merge. NB: after a SiteScore PR is merged, main HAS the file, so a follow-up revision must be a MODIFY on a fresh branch off the NEW main, not a re-add on the old base (else GitHub shows a both-added conflict).

**Accuracy checks to run every audit (learned on Arktek):** verify the tech stack from the live page source (`curl` + grep for `wp-content`/`generator`/`js_composer` etc), don't assume, Arktek = WordPress + WPBakery. Check time-sensitive scheme status on the live web, don't trust training: as of 2026-07, ECO4 is extended to 31 Dec 2026 with NO ECO5 successor (Warm Homes Plan, council-run, from 2027), so a site anchored on ECO4/LA Flex is building on a closing scheme (a finding, not a strength). Don't praise hero imagery as "genuine" without checking, Arktek's was low-quality stock/AI. Drop template-relative phrases like "this time nothing reached green" when cloning Synergi.

**Build workflow (reused for Arktek):** clone `sitescore/synergisw/index.html` as the template. Screenshots via Puppeteer in `site-greentide/post-booking` (has puppeteer installed) — hide (don't click) cookie/consent overlays for a clean hero, else you navigate to the cookie-policy page. Build dir per client = `meta-access/outputs/sitescore-<slug>/` (screenshots + crops + report.html). Embed shots as base64 JPGs + the client logo as a base64 SVG data-URI (NOT inline — avoids the `.st*`/`.logo-*` style-leak). Client brand colour fills the weak scores + callouts (Arktek red `#BE1E2D`, navy `#2E3E4F`); InstallrHub green stays "good/recommended". Inject via a node script replacing `{{PLACEHOLDER}}` tokens. NB the file lives in a SEPARATE repo `site-installrhub/installrhub-static` (remote blc-charlieharris-gh/site-installrhub), not marketing-agent.
