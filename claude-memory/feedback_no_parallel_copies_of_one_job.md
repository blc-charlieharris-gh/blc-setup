Charlotte 11-01: "stop creating these drifts and messy forks in the process." Website steps 6/7/9/10 had grown four
different save-and-copy boxes, step 9's Copy kept its own answer list beside From the client, and the Email client
already had a portal tick when I added a second one.

**Why:** each parallel copy drifts (different progress, different copy wording, gaps like tick-only answers), and she
then finds the gaps one at a time and has to re-explain.

**How to apply:** before adding a control, list or prompt, grep for the existing one (a tick, a list such as From the
client, a shared component) and make that one work. When fixing one step, check its siblings use the same piece; if
not, merge them in the same change and delete the old copy (no dead functions left). Builds on
[[feedback-whole-impact-before-any-change]].
