On Hub screens (Crew website steps especially), keep words to the action at that spot. Never add a line that explains something already covered in another step or panel, like "for go-live, waiting on the client" when step 8 and the go-live audit already handle it. No internal jargon ("Layer B", rule ids, check keys) in anything the builder reads. One place to act per item.

**Why:** Charlotte 10-25: "extra text like this just confuses where it's not needed… don't overexplain if it's covered somewhere else."

**How to apply:** before adding a sentence to a panel, ask "does the person need this here to act?" If not, or if it's covered elsewhere, leave it out. Related: [[feedback-build-gates-must-never-need-claude]].
