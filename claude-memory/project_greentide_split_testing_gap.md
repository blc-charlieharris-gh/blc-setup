Diagnosed 2026-07-16. Charlotte asked why she can't see Greentide landing-page split-test results.

**The test IS running and tracking.** The Green Tide **solar** funnel (`client_funnels.slug='greentide'`, tech solar, live) beacon has fired 39 `funnel_events`: landing views split **variant a = 20, variant b = 14** over 8-15 Jul, plus a few qualify/dq. The **heat-pump** funnel has **0 events** (beacon not firing there / no funnel traffic).

**Why nothing shows (two gaps):**
1. **Results page is an unwired stub.** `src/pages/hub/ClientTesting.jsx` (route `/clients/testing`) renders a hardcoded "No tests to show yet... will surface here once wired" empty state and never queries `funnel_events`.
2. **No test record to key off.** `funnel_tests` table is EMPTY (0 rows) and every `funnel_event` has `test_id = null`, so even a built UI can't tie events to a named test. The beacon assigns a/b but doesn't send a `test_id`.

**Also:** volume is tiny (34 landing views) = no statistical signal yet even once wired.

**To fix (parked task):** wire `ClientTesting` to `funnel_events` (variant a/b conversion by slug/step), create a `funnel_tests` row for the live GT solar test, and have the beacon emit its `test_id`. Tables (`funnel_tests`, `client_funnels`, `funnel_events`, `funnel-beacon` edge fn) all exist + deployed. **Update 2026-07-29 — lead→variant join has NO KEY + the `gt_exp` compound.** Charlotte: solar tracks worse than HP (4/7 vs 7/8), saw `solar_hero:a,hp_form_header:a` on Fillout leads. Verified in DB:

- Why 4/7 vs 7/8: (a) higher instant-form share on solar = more structurally-unmatchable leads; (b) HYPOTHESIS (frontend parser not in this workdir) that a comma-joined compound gt_exp fails a single-`test:variant` matcher, dropping solar leads; HP more often clean single so matches.
- Two levers when unparked: make parser comma-safe (small); pipe Fillout hidden `gt_exp` + visitor_id into intake so leads carry a variant (structural). Related [[project_greentide_solar_landing_tracking_gap]] [[project_greentide_inhouse_forms]].
