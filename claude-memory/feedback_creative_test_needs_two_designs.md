A creative test needs at least 2 designs (Charlotte 10-31: "2 min needed for a test, remember"). The Hub's Launch windows refuse a new test with one design (launchSave tooFewForTest, branch fix/marketplace-meta-buttons-test-two-designs-1031); adding one design to a test already running is fine.

**Why:** a one-design "test" has nothing to compare; the old one-design "Hub test" fallback let it through.

**How to apply:** any new launch/test flow or plan must keep the 2-design minimum; never suggest a one-design test. Related: [[feedback_creative_testing_model]].
